# Rusty brand

- Wordmark: "rusty", lowercase, in Squada One (Google Fonts).
- Mascot: Rusty, a rusty retro TV with no face (artwork made by Javi with Gemini, 2026-11-22). Transparent PNGs, 1024px, in `mascot/`:
  - `rusty-idle.png`: cream blank screen + popcorn. Welcome and success; put text on the screen (box: left 17.3%, top 36%, width 40%, height 35.3% of the image).
  - `rusty-off.png`: dark screen, zz. Loading, "not monitored yet".
  - `rusty-broken.png`: static, cracked corner, smoke. Nothing found, service down.
  - `rusty-mark.png`: idle TV without popcorn, for the header mark and app icon.
- `mascot/v1/`: the earlier face version (wink, sleeping, frown, confetti), kept for reference.
- UI colors: ground #0D0D0F, surface #16161A, text #F3F1EC, amber #F2A93B (by hand / primary), teal #4FC3B8 (automatic). Text on Rusty's screen: #3B2A1E.
